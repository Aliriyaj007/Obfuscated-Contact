User Guide & Instructions

What is Obfuscated Contact?

Obfuscated Contact helps protect your email address and phone number from spam bots and scrapers that harvest contact information from websites.

Instead of displaying your real contact info, you display scrambled versions that bots can't read but real humans can access.

Quick Start

  1. Enter your email address (and optionally phone number) in the input section
  2. Click "Generate Obfuscated Versions"
  3. Choose an obfuscation method from the tabs
  4. Copy the code snippet and paste it into your website

Available Obfuscation Methods

  • URI Encoding - Encodes special characters for use in URLs. Best for JavaScript-heavy sites.
  • HTML Entities - Replaces characters with HTML codes. Works on any website.
  • ROT13 - Simple letter substitution. Creates human-readable puzzles.
  • Hex Encoding - Converts to hexadecimal representation. Good for advanced protection.
  • Custom Pattern - Create your own pattern for maximum flexibility.

Security Ratings

Each method has a security rating (1-3 bars):

  • 1 bar - Basic protection against simple bots
  • 2 bars - Good protection against most scrapers
  • 3 bars - Strong protection against advanced bots

How to Use on Your Website

  1. Generate your obfuscated contact information
  2. Copy the entire code snippet (not just the obfuscated text)
  3. Paste the code into your website's HTML where you want the contact link to appear
  4. Save and publish your website
  5. Test the link to make sure it works

Tips for Best Results

  • Use HTML Entities for maximum compatibility
  • Test your contact links after publishing
  • Consider using multiple methods on different pages
  • Update your obfuscated info periodically for added security

Customization Options

Click the Settings button to access customization options:

  • Themes - Choose from 8 visually distinct themes
  • UI Density - Adjust spacing and sizing for your preference
  • Copy Behavior - Customize how copy actions work
  • Method Selection - Enable/disable specific obfuscation methods
  • Import/Export - Save and restore your settings

Custom Pattern Builder

Create your own obfuscation pattern in the Advanced Settings:

  1. Enable Advanced Settings in the Settings panel
  2. Enter a pattern like "c[#1]@[#2].[#3]"
  3. Use [#1], [#2], etc. as placeholders for email parts
  4. Click "Apply Pattern" to use your custom method
